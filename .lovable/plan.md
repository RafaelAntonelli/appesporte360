# Código único de matrícula no perfil do aluno

## Código de matrícula
- Garantir no banco que cada aluno tenha um código de matrícula exclusivo.
- Preservar os códigos atuais e impedir futuros códigos duplicados.
- Manter a geração automática do código para novos alunos.

## Perfil do aluno
- Incluir o código de matrícula nos dados carregados do aluno.
- Exibir o código de forma visível no perfil e nos detalhes do aluno.

## Validação
- Conferir se existem códigos repetidos antes de aplicar a proteção.
- Verificar compilação, testes e exibição do perfil.
